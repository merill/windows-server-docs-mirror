# Manage Role Based Access Control with Server Manager | Microsoft Learn

You can use the following topics to manage role based access control by using Server Manager, which has a graphical user interface.

- [Create a User Role for Access Control](create-a-user-role-for-access-control)
- [Create an Access Policy](create-an-access-policy)
- [Set Access Scope for a DNS Zone](set-access-scope-for-a-dns-zone)
- [Set Access Scope for DNS Resource Records](set-access-scope-for-dns-resource-records)
- [View Roles and Role Permissions](view-roles-and-role-permissions)

Alternately, you can use Windows PowerShell to manage IPAM role based access control. For more information, see [Manage Role Based Access Control with Windows PowerShell](manage-role-based-access-control-with-windows-powershell).
