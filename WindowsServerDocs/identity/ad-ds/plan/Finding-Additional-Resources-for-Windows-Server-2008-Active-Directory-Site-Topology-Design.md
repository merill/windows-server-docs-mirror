# Finding Additional Resources for Windows Server 2008 Active Directory Site Topology Design | Microsoft Learn

You can find the following documentation about Active Directory Domain Services (AD DS) on the Windows Server 2003 and Windows Server 2008 TechCenter websites:

- For more information about the process of locating a domain controller, see [Active Directory Collection](/en-us/previous-versions/windows/it-pro/windows-server-2003/cc780036%28v=ws.10%29).
- For more information about designing and deploying print servers, see [Designing and Deploying Print Servers](/en-us/previous-versions/windows/it-pro/windows-server-2003/cc785842%28v=ws.10%29).
- For more information about spanning trees and Active Directory replication topology, see [Active Directory Replication Topology Technical Reference](/en-us/previous-versions/windows/it-pro/windows-server-2003/cc755326%28v=ws.10%29).
- For more information about using Adlb.exe and managing environments that have 100 or more branch sites, see [Review Bridgehead Server Load-Balancing Improvements with Windows Server 2008 RODCs](/en-us/previous-versions/windows/it-pro/windows-server-2008-r2-and-2008/dd735927%28v%3dws.10%29).
- For information about installing Network Monitor, see [Monitoring network traffic](/en-us/previous-versions/windows/it-pro/windows-server-2003/cc783075%28v=ws.10%29).
- For worksheets to assist you in documenting your Windows Server 2008 AD DS site topology design, see [Job Aids for Windows Server 2003 Deployment Kit](https://microsoft.com/download/details.aspx?id=9608).
- For more information about shortcut trusts between domains, see [Understanding When to Create a Shortcut Trust](/en-us/previous-versions/windows/it-pro/windows-server-2008-r2-and-2008/cc754538%28v=ws.11%29).
- For more information about deploying the forest root domain, see [Deploying a Windows Server 2008 Forest Root Domain](/en-us/previous-versions/windows/it-pro/windows-server-2008-r2-and-2008/cc731174%28v=ws.10%29).
- For more information about securing domain controllers, see [AD DS Design and Planning](ad-ds-design-and-planning).
- For more information about deploying regional domains, see [Deploying Windows Server 2008 Regional Domains](/en-us/previous-versions/windows/it-pro/windows-server-2008-r2-and-2008/cc755118%28v=ws.10%29).
- For more information about how universal group caching works, see [How the Global Catalog Works](/en-us/previous-versions/windows/it-pro/windows-server-2003/cc737410%28v=ws.10%29).
- For more information about how to create site objects, see [Create a Site](/en-us/previous-versions/windows/it-pro/windows-server-2008-r2-and-2008/cc772304%28v=ws.11%29).
- For more information about how to create subnet objects, see [Create a Subnet](/en-us/previous-versions/windows/it-pro/windows-server-2008-r2-and-2008/cc770372%28v=ws.11%29).
- For more information about how to use the Active Directory Sites and Services snap-in to disable the **Bridge all site links** setting, see [Enable or disable site link bridges](/en-us/previous-versions/windows/it-pro/windows-server-2003/cc738789%28v=ws.10%29).
- For more information about read-only domain controller (RODC) features, see [AD DS: Read-Only Domain Controllers](/en-us/previous-versions/windows/it-pro/windows-server-2008-r2-and-2008/cc732801%28v=ws.10%29).
- For information about how to deploy an RODC, see the [Read-Only Domain Controllers Step-by-Step Guide](/en-us/previous-versions/windows/it-pro/windows-server-2008-r2-and-2008/cc772234%28v=ws.10%29).
