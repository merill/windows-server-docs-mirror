# Finding Additional Resources for Logical Structure Design | Microsoft Learn

You can find Additional Resources for Logical Structure Design in the following documentation about Active Directory Domain Services (AD DS):

- For more information about designing the site topology, see [Designing the Site Topology for Windows Server 2008 AD DS](designing-the-site-topology).
- For worksheets to assist you in documenting the proposed forest, domain, Domain Name System (DNS) infrastructure, and organizational unit (OU) design, download Job\_Aids\_Designing\_and\_Deploying\_Directory\_and\_Security\_Services.zip from [Job Aids for Windows Server 2003 Deployment Kit](https://microsoft.com/download/details.aspx?id=9608).
- For more information about delegated authentication and constrained delegation, see [Delegating authentication](/en-us/previous-versions/windows/it-pro/windows-server-2003/cc739740%28v=ws.10%29).
- For more information about configuring firewalls for use with AD DS, see [Active Directory in Networks Segmented by Firewalls](/en-us/troubleshoot/windows-server/identity/config-firewall-for-ad-domains-and-trusts).
- For more information about upgrading Active Directory domains to Windows Server 2008, see [Upgrading Active Directory Domains to Windows Server 2008 and Windows Server 2008 R2 AD DS Domains](/en-us/previous-versions/windows/it-pro/windows-server-2008-r2-and-2008/cc731188%28v=ws.10%29).
- For more information about restructuring AD DS domains within and between forests, see [ADMT Guide: Migrating and Restructuring Active Directory Domains](/en-us/previous-versions/windows/it-pro/windows-server-2008-r2-and-2008/cc974332%28v=ws.10%29).
- For more information about deploying a forest root domain, see [Deploying a Windows Server 2008 Forest Root Domain](/en-us/previous-versions/windows/it-pro/windows-server-2008-r2-and-2008/cc731174%28v=ws.10%29).
- For more information about deploying DNS, see [Deploying Domain Name System (DNS)](/en-us/previous-versions/windows/it-pro/windows-server-2003/cc780661%28v=ws.10%29).
- For more information about the DNS hierarchy and name resolution process, see the [DNS Technical Reference](/en-us/previous-versions/windows/it-pro/windows-server-2003/cc779926%28v=ws.10%29).
- For more information about how DNS supports AD DS, see the [DNS Support for Active Directory Technical Reference](/en-us/previous-versions/windows/it-pro/windows-server-2003/cc781627%28v=ws.10%29).
- For more information about WINS, see the [WINS Technical Reference](/en-us/previous-versions/windows/it-pro/windows-server-2003/cc736411%28v=ws.10%29).
- For more information about creating a disjoint namespace, see [Create a Disjoint Namespace](/en-us/previous-versions/windows/it-pro/windows-server-2003/cc755926%28v=ws.10%29).
- For more information about setting Service Principal Names (SPNs), see [Service Logons Fail Due to Incorrectly Set SPNs](/en-us/previous-versions/windows/it-pro/windows-server-2003/cc772897%28v=ws.10%29).
- For more information about how to delegate permissions to modify SPNs to subordinate administrators, see [Delegating Authority to Modify SPNs](/en-us/previous-versions/windows/it-pro/windows-server-2008-R2-and-2008/cc770439%28v=ws.10%29).
- For more information about domain controller certificate requirements, see article 321051 in the Microsoft Knowledge Base, [How to enable LDAP over SSL with a third-party certification authority](https://support.microsoft.com/help/321051/).
- For more information about Lightweight Directory Access Protocol (LDAP) over Secure Sockets Layer (SSL) (LDAPS) authentication for Windows Server 2003, see article 938703 in the Microsoft Knowledge Base, [How to troubleshoot LDAP over SSL connection problems](https://support.microsoft.com/help/938703/).
- For more information about Group Policy infrastructure, see [Designing a Group Policy Infrastructure](/en-us/previous-versions/windows/it-pro/windows-server-2003/cc786524%28v=ws.10%29).
- For more information about read-only domain controllers (RODCs), see [AD DS: Read-Only Domain Controllers](/en-us/previous-versions/windows/it-pro/windows-server-2008-r2-and-2008/cc732801%28v=ws.10%29).
- For more information about fine-grained password and account lockout policies, see the [AD DS Fine-Grained Password and Account Lockout Policy Step-by-Step Guide](/en-us/previous-versions/windows/it-pro/windows-server-2008-r2-and-2008/cc770842%28v=ws.10%29).
- For more information about naming conventions in AD DS, see article 909264 in the Microsoft Knowledge Base, [Naming conventions in Active Directory for computers, domains, sites, and OUs](https://support.microsoft.com/help/909264/).
