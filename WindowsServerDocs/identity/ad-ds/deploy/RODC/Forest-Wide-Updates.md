# Active Directory Forest-Wide Updates | Microsoft Learn

You can review the following set of changes to help understand and prepare for the schema updates that are performed when running `adprep /forestprep` on Windows Server.

Beginning in Windows Server 2012, Adprep commands run automatically as needed during AD DS installation. They can also be run separately in advance of AD DS installation. For more information, see [Running Adprep.exe](/en-us/previous-versions/windows/it-pro/windows-server-2008-R2-and-2008/dd464018%28v=ws.10%29).

Important

Forest-wide schema updates are performed cumulatively by `adprep`. For example, operations 131 - 135 are performed before operations 136 - 142.

For more information about how to interpret the access control entry (ACE) strings, see [ACE strings](/en-us/windows/win32/secauthz/ace-strings). For more information about how to interpret the security ID (SID) strings, see [SID strings](/en-us/windows/win32/secauthz/sid-strings).
