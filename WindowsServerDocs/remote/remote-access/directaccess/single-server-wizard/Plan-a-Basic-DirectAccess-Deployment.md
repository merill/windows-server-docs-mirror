# Plan a Basic DirectAccess Deployment | Microsoft Learn

This topic describes the planning steps required to deploy a single DirectAccess server running Windows Server 2016, Windows Server 2012 R2, or Windows Server 2012 with basic features:

1. [Step 1: Plan the Basic DirectAccess Infrastructure](da-basic-plan-s1-infrastructure)-Plan network and server topology, firewall settings, certificate requirements, DNS and Active Directory.
2. [Step 2: Plan the Basic DirectAccess Deployment](da-basic-plan-s2-deployment)-Plan client and server deployment.
