# Services for Network File System (NFS) command-line tools | Microsoft Learn

Services for Network File System (NFS) provides a file sharing solution that lets you transfer files between computers running Windows Server and UNIX operating systems using the NFS protocol.

Information and links to each of the associated NFS command-line tools:

| Command | Description |
| --- | --- |
| [mapadmin](mapadmin) | Manage User Name Mapping for Microsoft Services for Network File System. |
| [mount](mount) | Mount Network File System (NFS) network shares. |
| [nfsadmin](nfsadmin) | Manage Server for NFS and Client for NFS. |
| [nfsshare](nfsshare) | Control Network File System (NFS) shares. |
| [nfsstat](nfsstat) | Display or reset counts of calls made to Server for NFS. |
| [rpcinfo](rpcinfo) | List programs on remote computers. |
| [showmount](showmount) | Display mounted directories. |
