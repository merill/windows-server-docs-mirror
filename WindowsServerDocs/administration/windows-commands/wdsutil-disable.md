# wdsutil disable | Microsoft Learn

Disables all services for Windows Deployment Services.

## Parameters

| Parameter | Description |
| --- | --- |
| [wdsutil disable-server command](wdsutil-disable-server) | Disables all Windows Deployment Services services on a specified server (Deployment Server). |
| [wdsutil disable-transportserver command](wdsutil-disable-transportserver) | Disables all Windows Deployment Services services on a specified Transport Server. |
