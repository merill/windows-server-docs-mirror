# bitsadmin peercaching | Microsoft Learn

Lists the /peercaching switches.

Lists the /peercaching switches.

## Syntax

```
bitsadmin /peercaching /help
bitsadmin /peercaching /setconfigurationflags
bitsadmin /peercaching /getconfigurationflags
```

### Parameters

| Parameter | Description |
| --- | --- |
| [bitsadmin peercaching and help](bitsadmin-peercaching-and-help) | Displays the command-line usage for the /peercaching switches. |
| [bitsadmin peercaching and setconfigurationflags](bitsadmin-peercaching-and-setconfigurationflags) | Sets the configuration flags that determine if the computer can serve content to peers and if it can download content from peers. |
| [bitsadmin peercaching and getconfigurationflags](bitsadmin-peercaching-and-getconfigurationflags) | Gets the configuration flags that determine if the computer serves content to peers and if it can download content from peers. |
