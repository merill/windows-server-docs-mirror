# wdsutil enable | Microsoft Learn

Enables all services for Windows Deployment Services.

## Parameters

| Parameter | Description |
| --- | --- |
| [wdsutil enable-server command](wdsutil-enable-server) | Enables all services on a specified Windows Deployment Services server (Deployment Server). |
| [wdsutil enable-transportserver command](wdsutil-enable-transportserver) | Enables all services on a specified Transport Server. |
