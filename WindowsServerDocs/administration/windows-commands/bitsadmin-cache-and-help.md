# bitsadmin cache and help | Microsoft Learn

Displays the command-line usage for the **cache** switches.

## Syntax

```
bitsadmin /cache /help
```

## Examples

To show the command-line help for the **cache** switches.

```
bitsadmin /cache /help
```
