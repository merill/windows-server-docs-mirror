# wdsutil add | Microsoft Learn

## Parameters

| Parameter | Description |
| --- | --- |
| [wdsutil add-device command](wdsutil-add-device) | Pre-stages a computer in active directory. |
| [wdsutil add-image command](wdsutil-add-image) | Adds boot or installation images. |
| [wdsutil add-imagegroup command](wdsutil-add-imagegroup) | Adds an image group. |
| [wdsutil add-drivergrouppackage command](wdsutil-add-drivergrouppackage) | Adds a driver package to a driver group. |
| [wdsutil add-drivergrouppackages command](wdsutil-add-drivergrouppackages) | Adds driver packages to a driver group. |
| [wdsutil add-driverpackage command](wdsutil-add-driverpackage) | Adds a driver package to the server. |
| [wdsutil add-imagedriverpackage command](wdsutil-add-imagedriverpackage) | Adds a driver package that is in the driver store to an existing boot image on the server. |
| [wdsutil add-imagedriverpackages command](wdsutil-add-imagedriverpackages) | Adds driver packages from the driver store to a boot image on the server. |
| [wdsutil add-alldriverpackages subcommand](wdsutil-add-alldriverpackages) | Adds driver packages from a folder to a server. |
| [wdsutil add-drivergroup command](wdsutil-add-drivergroup) | Adds a driver group to a server. |
| [wdsutil add-drivergroupfilter command](wdsutil-add-drivergroupfilter) | Adds a filter to a driver group on a server. |
