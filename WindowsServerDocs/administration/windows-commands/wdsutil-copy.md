# wdsutil copy | Microsoft Learn

Copies an image or a driver group.

## Parameters

| Parameter | Description |
| --- | --- |
| [wdsutil copy-image command](wdsutil-copy-image) | Copies images that are within the same image group. |
| [wdsutil copy-drivergroup command](wdsutil-copy-drivergroup) | Copies an existing driver group on the server. |
