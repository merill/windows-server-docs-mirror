# wdsutil new | Microsoft Learn

Creates capture and discover images, multicast transmissions, and namespaces.

## Subcommands

| Subcommand | Description |
| --- | --- |
| [wdsutil new-captureimage command](wdsutil-new-captureimage) | creates a new capture image from an existing boot image. |
| [wdsutil new-discoverimage command](wdsutil-new-discoverimage) | creates a new discover image from an existing boot image. |
| [wdsutil new-multicasttransmission command](wdsutil-new-multicasttransmission) | creates a new multicast transmission. |
| [wdsutil new-namespace command](wdsutil-new-namespace) | creates a new namespace. |
