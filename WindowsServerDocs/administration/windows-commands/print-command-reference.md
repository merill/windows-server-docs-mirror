# Print command-line tool reference | Microsoft Learn

Information and links to each of the associated print command-line tools:

| Command | Description |
| --- | --- |
| [lpq](lpq) | Displays the status of a print queue on a computer running Line printer Daemon (LPD). |
| [lpr](lpr) | Sends a file to a computer or printer sharing device running the Line printer Daemon (LPD) service in preparation for printing. |
| [Net print](net-print) | Displays information about a specified printer queue, displays information about a specified print job, or controls a specified print job. |
| [print](print) | Sends a text file to a printer. |
| [prncnfg](prncnfg) | Configures or displays configuration information about a printer. |
| [prndrvr](prndrvr) | Adds, deletes, and lists printer drivers. |
| [prnjobs](prnjobs) | Pauses, resumes, cancels, and lists print jobs. |
| [prnmngr](prnmngr) | Adds, deletes, and lists printers or printer connections, in addition to setting and displaying the default printer. |
| [prnport](prnport) | Creates, deletes, and lists standard TCP/IP printer ports, in addition to displaying and changing port configuration. |
| [prnqctl](prnqctl) | Prints a test page, pauses or resumes a printer, and clears a printer queue. |
| [pubprn](pubprn) | Publishes a printer to the active directory directory service. |
| [rundll32 printui.dll,printUIEntry](rundll32-printui) | Enables you to automate the installation and configuration of printers using scripts or the command prompt. |
