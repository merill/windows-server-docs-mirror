## Windows Server and Azure

Discover some of the ways you can enhance Windows Server with Azure services

![](media/index/azure-arc-icon.svg)[Azure Arc](/en-us/azure/azure-arc/servers/overview)
Simplify governance and management by delivering a consistent multicloud and on-premises management platform.

![](media/index/hotpatch-icon.svg)[Hotpatch](get-started/hotpatch)
Install security updates without having to restart Windows Server.

![](media/index/cost-budget-icon.svg)[Pay-as-you-go licensing](get-started/windows-server-pay-as-you-go)
An alternative to perpetual licensing, only pay for as much as you use.

![](media/index/recovery-services-vault-icon.svg)[Azure Site Recovery](/en-us/azure/site-recovery/site-recovery-overview)
Help ensure business continuity by keeping business apps and workloads running during outages.
